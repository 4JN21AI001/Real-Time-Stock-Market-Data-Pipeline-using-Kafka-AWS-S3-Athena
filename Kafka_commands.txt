Start Zoo-keeper:
-------------------------------
bin/zookeeper-server-start.sh config/zookeeper.properties

Open another window to start kafka
But first ssh to to your ec2 machine as done above


Start Kafka-server:
---------------------------------------------
Duplicate the session & enter in a new console --
export KAFKA_HEAP_OPTS="-Xmx256M -Xms128M"
cd kafka_2.13-3.7.0
bin/kafka-server-start.sh config/server.properties

It is pointing to private server , change server.properties so that it can run in public IP 

To do this , you can follow any approaches shared below --
Do a "sudo nano config/server.properties" - change ADVERTISED_LISTENERS to public ip of the EC2 instance

Everytime when you start freshly the process, the IP address gone change every time
If you dont want to change the IP address everytime, you can follow this approach shared below —

Use Elastic IP, this is permanent public IP
Steps:
Go to AWS Console —> EC2 —> Elastic IP —> Allocate Elastic IP —> Associate with your instance

Create the topic:
-------------------------------
Duplicate the session & enter in a new console --
cd kafka_2.13-3.7.0
bin/kafka-topics.sh --create --topic demo_test --bootstrap-server {IP Address of EC2 Instance:9092} --replication-factor 1 --partitions 1

Start Producer:
-------------------------------
bin/kafka-console-producer.sh --topic demo_test --bootstrap-server {IP Address of EC2 Instance:9092}

Start Consumer:
-------------------------------
Duplicate the session & enter in a new console --
cd kafka_2.13-3.7.0
bin/kafka-console-consumer.sh --topic demo_test --bootstrap-server {IP Address of EC2 Instance:9092}

Additional Kafka Commands
-------------------------------
sudo lsof -i :2181 (To see zookeeper is running or not)

bin/zookeeper-server-stop.sh (To stop zookeeper)

sudo lsof -i :9092 (To see Kafka is running or not)

bin/kafka-server-stop.sh (To stop Kafka)
